🐳 Docker Ready

Containerized runtime for fast onboarding and repeatable deployments.

Compose Profiles

  • Default compose path for app + SQLite development
  • postgres profile for app + PostgreSQL stack

Common Commands

# SQLite profile
docker-compose up -d

# PostgreSQL profile
docker-compose --profile postgres up -d

# Follow logs
docker-compose logs -f app

# Stop containers
docker-compose down

Engineering Practices

  • Keep runtime configuration in environment variables
  • Use health checks for service readiness
  • Avoid baking secrets into images
  • Pin critical image versions to improve reproducibility
