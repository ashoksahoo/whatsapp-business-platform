🔐 API Key Authentication

Authentication and authorization gate for protected REST endpoints.

Auth Contract

  • Header: Authorization: Bearer YOUR_API_KEY
  • Public endpoints: health check and webhook routes
  • All /api/v1 routes require valid API key

Security Model

  • Store only hashed keys (never plaintext)
  • Support key revocation and rotation
  • Track key usage in audit logs
  • Apply per-key rate limits for abuse control

Middleware Guidance

  • Extract and validate Bearer token format
  • Resolve key identity via secure hash verification
  • Attach caller context to request lifecycle
  • Return 401 Unauthorized on invalid credentials
