🖥️ React Dashboard

Frontend console for operational workflows around messages, contacts, and templates.

Functional Scope

  • Monitor and inspect conversations
  • Lookup and maintain contact records
  • Create and update message templates
  • Enable API operations without manual cURL workflows

Runtime

  • Frontend source: frontend/
  • Development command: npm run dev
  • Default local URL: http://localhost:5173

Integration Pattern

  • REST-first integration with backend API
  • Environment-driven API base URL configuration
  • Consistent loading/error/empty states across screens
