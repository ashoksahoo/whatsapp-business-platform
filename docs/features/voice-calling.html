🔜 Voice Calling (Coming Soon)

Planned capability for WhatsApp voice interactions, recordings, transcription, and call analytics.

Planned Scope

  • Voice session initiation and call lifecycle tracking
  • Recording pipeline and storage management
  • Speech-to-text transcription workflows
  • Call analytics (volume, duration, outcomes)

Architecture Direction

  • Signaling and media session coordination layer
  • Asynchronous enrichment pipeline for transcription
  • Structured event model for call state transitions
  • Dashboard surfaces for call monitoring and reporting

Roadmap Milestones

  • M1: baseline call session persistence
  • M2: recording capture and retention controls
  • M3: transcription indexing and search
  • M4: reporting and operational analytics
