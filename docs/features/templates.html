📋 Templates

Template lifecycle management for approved WhatsApp business messages with variable parameters.

Capabilities

  • List, create, update, delete template records
  • Store name, language, category, content, and status
  • Send template messages through POST /api/v1/messages

Endpoints

  • GET /api/v1/templates
  • GET /api/v1/templates/:id
  • POST /api/v1/templates
  • PATCH /api/v1/templates/:id
  • DELETE /api/v1/templates/:id

Data & Validation

  • Template variables use indexed placeholders (e.g. {{1}}, {{2}})
  • Outbound param count should match placeholder count
  • Status is expected to align with WhatsApp approval flow

Operational Guidance

  • Separate local template metadata from Meta approval state
  • Block sending non-approved templates in production
  • Version templates instead of mutating active production content

Example

{
  "to": "+1234567890",
  "message_type": "template",
  "template_name": "welcome_message",
  "template_language": "en",
  "template_params": ["John", "Acme"]
}
