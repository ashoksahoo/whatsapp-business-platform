🔔 Webhooks

Inbound event entrypoint for incoming WhatsApp messages and delivery state updates.

Endpoints

  • GET /webhooks/whatsapp — verification challenge
  • POST /webhooks/whatsapp — incoming events

Verification Flow

Meta sends hub.mode, hub.verify_token, and hub.challenge. The handler validates the token and echoes the challenge for successful webhook onboarding.

Security

  • Validate X-Hub-Signature-256 against the raw request body using app secret
  • Reject unsigned and invalidly signed payloads
  • Keep webhook route unauthenticated but signature-protected

Processing Semantics

  • Parse nested entry[].changes[] payload objects
  • Handle both incoming messages and status updates
  • Use idempotency safeguards for duplicate event retries
  • Acknowledge quickly (200 OK) and process async if needed

Example Payload Shape

{
  "object": "whatsapp_business_account",
  "entry": [{ "changes": [{ "value": { "messages": [] } }] }]
}
