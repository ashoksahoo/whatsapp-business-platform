👥 Contacts

Contact storage and search layer for conversation ownership, lookup, and profile updates.

Core Responsibilities

  • Store canonical contact records keyed by WhatsApp/E.164 number
  • Auto-create contacts on inbound webhook processing
  • Maintain interaction metadata (last message time, message count, unread count)
  • Support human updates (name/profile details) from API and dashboard

Endpoints

  • GET /api/v1/contacts
  • GET /api/v1/contacts/:id
  • PATCH /api/v1/contacts/:id
  • GET /api/v1/contacts/search?q=...

Engineering Guidance

  • Normalize phone numbers before persistence and search
  • Use indexed search fields for number and display name
  • Keep contact mutation idempotent during duplicate webhook deliveries
  • Avoid blocking message processing on optional profile enrichment
